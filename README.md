# BAST Finance — edición web

> **Tus finanzas. Tu control.**

Aplicación web de finanzas personales offline-first. Este repositorio contiene solo el build
estático publicado; el código fuente es privado y propietario.

- **App:** https://yeremisb.github.io/bast-finance-app/
- **Producto:** BAST Finance
- **Desarrollador:** YeremiSB
- **Moneda:** PEN (S/)
- **Privacidad:** los datos se guardan en el navegador de cada dispositivo. No hay backend.
- **Offline:** después de la primera carga, la PWA funciona sin conexión.

## Uso

1. Abre la aplicación en Edge o Chrome.
2. Instálala como PWA si quieres un acceso directo.
3. Exporta un backup JSON desde Configuración antes de limpiar el navegador o cambiar de
   dispositivo.
